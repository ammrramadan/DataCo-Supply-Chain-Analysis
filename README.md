# 📊 Supply Chain Data Analysis Project

## 📌 Project Overview

This project is an end-to-end **Data Analysis** project developed using a real-world **Supply Chain** dataset from Kaggle. The objective of the project is to transform raw business data into meaningful insights that support data-driven decision-making.

The project covers the complete data analysis lifecycle, including **data cleaning, preprocessing, SQL analysis, and interactive dashboard development** using Power BI.

---

## 🎯 Project Objectives

* Clean and prepare raw data for analysis.
* Analyze sales performance and profitability.
* Evaluate customer purchasing behavior.
* Analyze shipping and delivery performance.
* Identify top-performing products and markets.
* Build an interactive dashboard for business decision-making.

---

## 📂 Dataset Information

* **Dataset:** DataCo Supply Chain Dataset
* **Source:** Kaggle
* **Records:** 128,582
* **Columns:** 53
* **Format:** CSV

The dataset contains information about:

* Customers
* Products
* Orders
* Sales
* Profit
* Shipping
* Markets
* Delivery Performance

## 🔄 Project Workflow

### 1. Data Cleaning (Python)

* Loaded the dataset using Pandas.
* Explored the dataset structure.
* Handled missing values.
* Removed duplicate records.
* Performed data preprocessing.
* Encoded categorical columns where required.
* Prepared the dataset for analysis.

---

### 2. SQL Analysis

Business questions answered using SQL:

* Top-selling products.
* Most profitable products.
* Sales by market.
* Orders by category.
* Department profitability.
* Customer purchasing behavior.
* Shipping mode analysis.
* Late delivery analysis.
* Yearly sales analysis.
* INNER JOIN & LEFT JOIN between multiple tables.
